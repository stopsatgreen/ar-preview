# AR Preview

A minimal AR model viewer built with [Model Viewer](https://modelviewer.dev/). Displays a 3D model in the browser with support for AR on compatible devices.

## Usage

Open `index.html` in a browser, or deploy to any static hosting provider (Netlify config included).

## Deployment

The included `netlify.toml` sets correct MIME types for `.glb` and `.usdz` files.
